# **App Name**: DineEasy

## Core Features:

- QR Code Generation: Generate unique QR codes for each table, managed via admin panel.
- Order Placement: Customers place orders by scanning QR codes and providing their name and phone number.
- Real-time Order Display: Display new orders in real-time. A tool tracks occupied tables to aid seating assignments.
- Order Status Updates: Kitchen staff can update order status (Order Taken, Preparing, Ready to Serve, etc.).
- Order Monitoring: Customers can monitor their order status.
- Table Management: Administrators can assign table numbers to QR codes.
- Customer data capture: Capture customer contact details along with orders and integrate with the restaurants CRM platform.

## Style Guidelines:

- Primary color: Saturated, vibrant orange (#f4fdff) to evoke appetite and energy.
- Background color: Desaturated light orange (#F5f5dc) for a warm and inviting feel.
- Accent color: Analogous yellow (#ffcfa3) for highlights and interactive elements, creating contrast.
- Headline font: 'Playfair', a modern serif font that gives a high-end feel.
- Body font: 'PT Sans', a humanist sans-serif to use for body text.
- Simple, clear icons to represent order status and table management functions.
- Clean, card-based layout for orders, easy to view on both customer and staff interfaces.
- Subtle animations for order status updates and new order notifications.
